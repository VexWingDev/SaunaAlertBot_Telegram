# Мониторинг слотов сауны

Эта программа следит за календарём бронирования DAS Eero и отправляет
сообщение в Telegram, когда появляется свободный слот сауны.
По умолчанию программа проверяет скользящий период в 14 дней каждые 2 минуты.

## Важные примечания

Бот в основном предназначен для жилого комплекса DAS - Eero, где доступна
сауна. Однако несколькими изменениями в коде и API его можно настроить для
другого участка DAS или любого другого места. Главное, что потребуется
изменить, - это API. Используйте программу по своему усмотрению.

Ниже приведено руководство по запуску бота.

В репозитории есть файл `example.env` с примером настройки секретов.
**Помните:** не передавайте секреты людям или искусственному интеллекту.

### 1. Установите Python

Используйте Python 3.10 или новее.

Проверьте версию:

	python --version

### 2. Установите зависимости

	python -m pip install -r requirements.txt

## 3. Создайте бота Telegram

В Telegram откройте **@BotFather** и используйте команду `/newbot`.

Сохраните токен в переменной окружения `TELEGRAM_BOT_TOKEN`.

Затем откройте созданного бота и отправьте ему `/start`.

Выполните:

	python monitor.py chat-id

Команда выведет последние идентификаторы чатов. Сохраните свой личный
идентификатор чата в переменной `TELEGRAM_CHAT_ID`.

## 4. Проверьте Telegram

Установите обе переменные окружения и выполните:

	python test_telegram.py

Вы должны получить сообщение в Telegram.

## 5. Проверьте доступ

Выполните:

	python monitor.py

Если API этого контракта доступен для публичного чтения, мониторинг начнётся
сразу.

Если вы видите:

	AUTHENTICATION REQUIRED

установите `DAS_COOKIE`, указав полное значение заголовка Cookie запроса
браузера во время входа в DAS.

### Как получить DAS_COOKIE

1. Откройте в браузере страницу арендаторов нужного участка.
2. Нажмите F12 -> Network. (Или щёлкните правой кнопкой мыши и выберите
   `inspect...`.)
3. Перезагрузите страницу.
4. Нажмите на запрос `time-slots?...`.
5. В разделе Request Headers найдите `Cookie`.
6. Скопируйте значение после `Cookie:` в `DAS_COOKIE`.

Не копируйте и не передавайте заголовки `Authorization`, пароли и другие
секреты. Не передавайте их людям или искусственному интеллекту.
***Это представляет угрозу безопасности.***

Срок действия cookies истекает. Если позже монитор начнёт возвращать 401/403,
обновите вход и cookie.

## Как определяется доступность

Ответ API содержит записи, например:

	"status": "reserved"
	"status": "own"

Они считаются недоступными.

По умолчанию доступными считаются значения:

	available
	free
	open

Если в журнале появляется неожиданное значение статуса, хотя на сайте слот
выглядит свободным, добавьте это значение в `AVAILABLE_STATUSES`.

Например:

	AVAILABLE_STATUSES=available,free,open,unreserved

## Непрерывная работа

На домашнем компьютере оставьте терминал открытым.

В Windows Планировщик заданий может запускать:

	python C:\path\to\monitor.py

В Linux рекомендуется использовать systemd.

Также подойдёт VPS, если программа должна работать круглосуточно.

## Примечания

- Программа **не бронирует** слоты. Она только отправляет уведомления.
- Состояние хранится в `state.json`, чтобы избежать повторных уведомлений -
  файл будет скачан автоматически, поэтому существует файл `download`.
- Временные метки API указаны в UTC; уведомления переводятся во временную
  зону Europe/Helsinki. При необходимости измените её на свой часовой пояс.
